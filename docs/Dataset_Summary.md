## Dataset Description

The DataCo Supply Chain Dataset contains transactional records related to customer orders, product sales, shipping activities, and delivery performance across multiple geographical locations.

The dataset provides sufficient information to analyze:

- Sales Performance
- Profitability
- Customer Behavior
- Product Performance
- Shipping Performance
- Delivery Delays
- Discount Impact
- Supply Chain Efficiency
